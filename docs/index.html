股票教练智能体使用说明

stock-trading-coach-agent 用于每日交易复盘：交易事实、交易想法、文章观点、宏观镜片、叙事污染检查、行为诊断和长期 playbook。

它做什么

保留交割单本地脱敏、隐私检查、指标计算和行为诊断。
记录 daily journal：当天交易想法、意图、情绪和计划。
提取文章观点并检查叙事污染。
手动蒸馏宏观博主观点，形成市场环境观察镜片。
读取懂哥短线方法与冰冰小美宏观镜片，生成双镜片教练判断。
优先使用免费公开行情快照校验指数、风格和候选池；接口失败时明确降级。
生成买点教练卡：买点分类、触发条件、止损锚点、禁止动作。
生成每日 HTML、Markdown 和 JSON 教练报告。
生成可发雪球的每日复盘与明日计划草稿。
保守沉淀 playbooks.json：可复制、待验证、应避免。
基于历史亏损模式生成买入前风控反问。

它不做什么

  • 不荐股。
  • 不预测未来涨跌。
  • 不提供买入、卖出或持有某只股票的建议。
  • 不把真实 PDF、CSV、XLSX 或截图提交到 GitHub。

默认用法

在 Codex 中说：

请使用 $stock-trading-coach-agent

或手动运行：

python3 scripts/interactive_runner.py --open

打开 http://127.0.0.1:8787 后，默认粘贴当天交割单文本，填写交易想法、你对市场的判断、文章信息和情绪标签。PDF/CSV/XLSX 上传只是可选入口。

序号    成交时间    证券代码    证券名称    委托方向    成交数量    成交价格    成交金额
1       09:40:15    301171     易点天下    证券买入    1500      34.900      52350.000

最终报告在 local_outputs/run_时间戳/daily_coach_report.html，稳定入口为 local_outputs/daily_coach_report.html。

雪球发布版在 local_outputs/run_时间戳/daily_xueqiu_post.html，稳定入口为 local_outputs/daily_xueqiu_post.html。

双镜片和买点指导

  • 懂哥镜片权重 80%，负责题材强度、技术位置、量能主动性、风险可定义和交易节点。
  • 冰冰小美镜片权重 20%，负责风格匹配、外部风险和叙事拥挤度约束。
  • 报告使用“硬判断 + 条件句”，不会只写“可以观察”。
  • 每只已交易股票会输出买点分类、触发条件、止损锚点和禁止动作。
  • 研究候选池优先尝试公开行情快照；若接口不可用或证据不足，再要求粘贴候选池或强势榜。
  • 如果没有 K 线或 200 日均线数据，报告必须标注“未确认 200 日均线位置”。

市场判断校正

  • 用户填写的市场判断只作为待校正输入，不直接当作结论。
  • 智能体会优先使用免费公开行情快照，独立判断主要指数、强弱板块、风格偏向、风险偏好和市场状态。
  • 当前优先级：新浪实时行情用于指数/个股快照，新浪全市场榜单用于候选池初筛，新浪日 K 用于 MA200；腾讯行情备用；东方财富 push2/push2his 用于榜单、板块和 K 线增强；AKShare 作为可选本地依赖。
  • 联网失败时，报告必须标注“市场背景未联网验证”，不能硬编。
  • 报告会指出你的判断中哪些成立、哪些可能是情绪化或过度归因、哪些信息缺失。

手动更新宏观镜片

例如蒸馏冰冰小美雪球主页最近文章：

python3 scripts/macro_lens_digest.py --source xueqiu --user-url "https://xueqiu.com/u/7143769715" --limit 50
  • 只保存标题、URL、摘要、宏观镜片和风险标签，不保存全文。
  • 宏观镜片只用于市场情况判断、教练解释和明日条件计划。
  • 如果雪球页面需要登录或反爬，脚本会提示使用具体文章 URL 或粘贴文本。

隐私边界

默认使用复制粘贴成交文本。真实文件只在本机处理。PDF 原文不交给 AI。截图成交单已降级为备用能力，只有在你显式发给 Codex 识别时才由 AI 提取标准 trades；请先裁剪或打码姓名、账号、资金余额。

  • 原始上传文件只进入系统临时目录，处理后删除。
  • local_outputs/ 保存真实报告，local_state/ 保存长期 playbook；两者都不提交 Git。
  • 文章 URL 可联网抓取，但长期只保存标题、URL、观点摘要和污染检查，不保存全文。
  • 雪球发布版可显示股票代码和名称，但成交金额默认转换为“单位”表达。

Playbook 规则

  • 单次交易成功不得直接进入“可复制”。
  • 至少 3 次类似证据后，才能从“待验证”升级为“可复制”。
  • 亏损或风险失控模式进入“应避免”。
  • 每条模式必须包含触发条件、入场理由类型、退出方式、最大风险、证据日期、验证状态。
